# 개인 공부 노트 스타일 (Obsidian)

## 프런트매터 (형식 그대로)

```yaml
---
notetoolbar: Mtoolbar
Main:
tags:
  - 태그1
  - 태그2
Link: "[[링크 노트]]"
Date: YYYY-MM-DD
---
```

## 본문 구조

- `# 주제` 제목 → 바로 아래 `---`
- 제목 아래 학습순서 한 줄: `※ 학습순서 : 단계1 > 단계2 > 단계3`
- 큰 주제 `## 1. ...`, 세부 항목 `### 1. ...`로 번호를 매긴다
- 기본 흐름 (해당 없는 항목은 생략)
  1. 기초 개념: 무엇이고 왜 필요한가
  2. 작동 원리: 어떻게 동작하는가
  3. 세부 내용: 종류, 비교, 용어, 수식
  4. 주의점/한계: 자주 하는 실수, 단점, 해결 방법
  5. 언제 쓰나: **실무 판단 규칙** (이런 상황이면 이걸 쓴다) + 그 이론 근거
- 개념 파트가 끝나면 `---` 후 `# 코드 예제` (코드가 필요할 때만)

## 작성 스타일

- 설명은 모두 불릿(-), "~이다 / ~한다" 체의 짧은 문장
- 개념마다 **한 줄 요약**을 먼저, 세부는 그 아래
- 핵심 용어·결론은 **굵게**
- 영어 용어는 처음에 한글(영어) 병기: 과대적합(Overfitting)
- 비교는 표로, 수식은 인라인으로 간단히
- 외울 게 많으면 앞글자 암기법 제시 (예: "완중업 재의통")
- 암기보다 **왜 그런지** 인과를 설명한다
- 입문자도 이해할 비유나 구체적 예시 1개 이상
- 그림 자리는 `![[이미지설명.png|400]]` 자리표시만

## 코드 스타일

```python
# ============================================================
# 주제 - 사용 데이터/목적
# ============================================================

# ─────────────────────────────
# 1. 데이터 로드
# ─────────────────────────────
```

- 한국어 주석, 부가 설명은 `→`, 출력값 해석은 `←`
  - 예: `print(f"R²: {r2:.4f}")  ← 1에 가까울수록 설명력이 높다`
- 복사해서 바로 실행 가능한 완결 코드 (import, 예제 데이터 포함)
- 난수는 `random_state=42` 고정
- 스케일러는 train에만 fit, test는 transform만 (데이터 누수 방지 주석)

## 작성 원칙

- 내용이 정확해야 한다. 다른 개념이 섞이거나 문장이 끊기지 않게
- 내가 준 초안이 있으면 그걸 기반으로 하되, 틀린 부분은 고치고 **무엇을 고쳤는지 따로** 알려준다
- 파일명: `분류_주제.md` (예: `ML_분류_로지스틱회귀.md`, `SQL_2과목_윈도우함수.md`)
