# 발표자료 스타일

## 반드시 지킬 것

- **배경은 흰색(RGB 255, 255, 255)만.** 어두운 배경·그라데이션 배경 금지.
- 메인 색은 **네이비**, 나머지는 강조용으로 아껴 쓴다.

## 색상 (RGB)

| 용도 | 색 | RGB |
|---|---|---|
| 메인(제목, 상단 바) | 네이비 | 0, 32, 96 |
| 보조(소제목, 도형) | 미디엄 블루 | 46, 84, 150 |
| 연한 면(표 헤더 배경, 박스) | 라이트 블루그레이 | 222, 230, 242 |
| 본문 텍스트 | 차콜 | 51, 51, 51 |
| 강조(핵심 수치 한 곳만) | 오렌지 | 237, 125, 49 |

## 레이아웃

- 상단: 네이비 얇은 바 + 슬라이드 제목(좌측 정렬)
- 제목 아래 한 줄 요약(헤드 메시지): 이 장에서 말하고 싶은 결론
- 본문은 개조식, 한 장에 bullet 5개 이하
- 하단: 페이지 번호, 회사·과제명은 작게

## 글꼴 크기

- 제목 24–28pt / 헤드 메시지 16–18pt / 본문 12–14pt / 각주 9–10pt

## 차트·표

- 차트 색은 네이비 계열 단계로, 비교 대상 하나만 오렌지
- 표 헤더는 라이트 블루그레이 배경 + 네이비 굵은 글씨

## 문체

- 문서와 같이 개조식 명사형 종결 ("~함", "~완료"). 자세한 규칙은 report-doc-style 스킬을 따른다.

## 채팅 답변 형식 (이 스킬의 다른 규칙보다 우선 적용)

- 말투는 자유롭게, 단 "~습니다", "~니다" 체는 쓰지 않음.
- 결론 먼저, 3~5줄 이내. 인사·서론·마무리 요약 없음.
- 코드, 코드 설명, 표, 정리 내용이 5줄 이상이면 채팅에 쓰지 않고 .md 파일로 전달함.
- 파일 전달 시 채팅에는 파일 설명 한 줄만 씀. 내용 재요약 없음.
- 5줄 미만 코드나 수정한 한두 줄은 채팅에 바로 씀.
