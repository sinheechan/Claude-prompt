# 스킬 추천

사용자가 이 스킬을 부르고 상황이나 질문을 주면, 주제·도구·환경을 가리지 않고 **지금 그 상황에 가장 맞는 스킬**을 추천한다.

## 절차

1. **상황 그대로 받기** — 범위를 따로 묻지 않는다. 준 상황과 대화 맥락에서 하려는 일, 쓰는 환경(claude.ai / Claude Code / API)을 추론한다. 도저히 판단이 안 될 때만 한 가지 묻는다.
2. **매번 웹 검색으로 지금 기준 확인** — 기억이나 아래 힌트 목록만으로 추천하지 않는다. 질문받은 시점의 최신 정보를 찾는다.
   - GitHub 저장소: 스타 수, 최근 커밋·릴리스 날짜, 이슈 상태
   - 스킬·플러그인 마켓플레이스와 디렉터리: 설치 수, 다운로드 수, 순위, 평점·리뷰
   - 큐레이션 목록(awesome 리스트 등)과 최근 글에서 반복 언급되는지
   - 공식 저장소(anthropics/skills) 여부
3. **후보 비교 기준** (위에서부터 중요)
   1. 지금 상황에 맞는가 — 아무리 인기 있어도 안 맞으면 제외
   2. 많이 쓰이는가 — 스타, 설치·다운로드 수, 언급 빈도
   3. 평가가 좋은가 — 평점·리뷰가 있으면 반영
   4. 살아있는가 — 최근 6개월 안에 업데이트됐는가
   5. 믿을 만한가 — 공식·유명 메인테이너 우선, 커뮤니티 스킬은 코드 확인 권고
4. **이미 설치된 스킬이 위 기준에서 충분하면** 그걸 1순위로 (설치 비용 0)
5. **맞는 스킬이 없으면 솔직하게** — 스킬 없이 바로 하면 되는지, 직접 만드는 게 나은지 말한다

## 추천 내용

- 추천 결과는 **.md 파일**로 만들어 전달한다. 파일명: `스킬추천_YYYYMMDD_작업명.md` (예: `스킬추천_20261107_WBS엑셀.md`)
- 파일 맨 위 `# 스킬 추천 — 작업명`, 그 아래 `> 상황: 사용자가 말한 상황 한 줄`
- 1순위 1개 + 대안 최대 2개를 **표 하나로**:

| 순위 | 스킬 | 상황 적합성 | 근거 수치 | 설치 | 비고 | Claude 판단 |
|---|---|---|---|---|---|---|
| 1 | **스킬명** (출처) | 지금 상황에 맞는 이유 | ★스타, 설치 수, 평점, 최근 업데이트 ([출처](링크)) | 설치 명령 또는 "불필요" | 주의점 | ✅ 추천 |

- 순위는 위 비교 기준(객관 지표) 순서, **Claude 판단**은 지금 상황을 보고 내 의견: ✅ 추천 / △ 참고만 / ✗ 비추천
- ✅는 하나만 단다. 순위 1위와 내 추천이 다르면 그대로 다르게 표시하고 이유를 아래에 쓴다.
- 근거 수치는 출처 링크를 셀 안에 붙인다. 못 찾은 수치는 "확인 안 됨"으로 쓰고 지어내지 않는다.
- 커뮤니티 스킬이면 비고에 "설치 전 SKILL.md·스크립트 확인"
- 채팅에는 파일 설명 한 줄과 Claude 추천 스킬명만 쓴다
- 표 아래 세 줄만 (파일 안):
  - `확인 기준: YYYY-MM-DD`
  - **Claude 추천**: 스킬명 — 한 줄 이유
  - **다음 행동** 한 줄

## 검색 출발점 (힌트일 뿐, 수치는 매번 새로 확인)

- 공식: anthropics/skills (docx, pdf, pptx, xlsx, skill-creator, frontend-design, mcp-builder, webapp-testing)
- 많이 언급되는 묶음: obra/superpowers (test-driven-development, systematic-debugging, subagent-driven-development)
- 내 스킬: github.com/sinheechan/Claude-skills (python-coding-style, report-doc-style, pptx-corporate-style, blog-post-chirpy, study-note-style)

## 설치 위치

- **claude.ai**: 스킬 폴더 zip → 설정의 스킬 메뉴에서 업로드
- **Claude Code**: `/plugin marketplace add <저장소>` → `/plugin install <이름>`, 또는 폴더를 `~/.claude/skills/`에 복사
- claude.ai와 Claude Code 스킬은 서로 동기화되지 않는다

## 채팅 답변 형식 (이 스킬의 다른 규칙보다 우선 적용)

- 말투는 자유롭게, 단 "~습니다", "~니다" 체는 쓰지 않음.
- 결론 먼저, 3~5줄 이내. 인사·서론·마무리 요약 없음.
- 코드, 코드 설명, 표, 정리 내용이 5줄 이상이면 채팅에 쓰지 않고 .md 파일로 전달함.- 파일 전달 시 채팅에는 파일 설명 한 줄만 씀. 내용 재요약 없음.
- 5줄 미만 코드나 수정한 한두 줄은 채팅에 바로 씀.
