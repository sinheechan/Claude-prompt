# 보고서 뼈대 템플릿

## A. 과제 진도·결과 보고서

```
1. 과제 개요
  가. 과제명 / 수행기간 / 수행기관
  나. 추진 배경 및 필요성
2. 추진 내용
  가. 단계별 추진 실적        <표> 계획 대비 실적
  나. 주요 기술 개발 내용     [그림] 시스템 구성도
3. 성과
  가. 정량 성과 (목표 대비 달성률)
  나. 정성 성과
4. 문제점 및 대응 방안
5. 향후 계획
```

## B. 사업계획서·제안서

```
1. 사업 개요
2. 현황 및 문제점
3. 해결 방안 (개발 내용)
  가. 핵심 기술
  나. 시스템 구성
4. 추진 체계 및 일정
5. 기대 효과 (정량 / 정성)
6. 사업화 및 활용 계획
```

## C. 회의록

```
- 일시 / 장소 / 참석자
- 안건
- 논의 내용 (안건별 개조식)
- 결정 사항
- 후속 조치 (담당 / 기한)
```
